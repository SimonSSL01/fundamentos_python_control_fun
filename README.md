# Fundamentos de Python - Control y Funciones

Este proyecto es una colección de ejercicios y ejemplos en Python organizados por conceptos fundamentales: condicionales, funciones e iteraciones.

## Estructura del proyecto

- `src/`
  - `condicionales/`: ejemplos de estructuras condicionales (`if`, `else`, `elif`, operadores lógicos y validaciones).
  - `funciones/`: ejemplos de definición y uso de funciones, parámetros, valores predeterminados, retorno de valores y buenas prácticas de documentación.
  - `iterativas/`: ejemplos de bucles `for` y `while`, uso de `break`, `continue`, `pass`, bucles anidados y procesamiento de colecciones.

## Qué contiene cada carpeta

### `src/condicionales`
Contiene scripts prácticos que demuestran cómo tomar decisiones en el código:
- Validación de edad y permisos (`eresAdulto.py`, `mayorEdad.py`, `licencia.py`, `puedeVotar.py`)
- Comparaciones numéricas (`numeroEs.py`, `numMayor.py`, `parImpar.py`)
- Verificaciones de contraseña y acceso (`contrasena.py`, `acceso.py`)
- Ejemplos de condiciones múltiples y selección de opciones (`queColor.py`, `queFruta.py`, `finSemana.py`)
- Manejo de datos y errores simples (`prevError.py`, `desDatos.py`, `credito.py`)

### `src/funciones`
Incluye archivos que enseñan conceptos clave de funciones en Python:
- Declaración básica y retorno de valores (`funcion_basica.py`, `return.py`, `funciones_sin_return.py`)
- Parámetros posicionales, por nombre y valores predeterminados (`parametros_posicionales.py`, `parametros_por_nombre.py`, `parametros_valores_predeterminados.py`)
- Documentación con docstrings (`docstrings.py`, `buenas_practicas_docstring.py`, `estructura_docstring.py`)
- Ejemplos de comportamiento especial y validación dentro de funciones (`docstring_comportamiento_especial.py`, `validacion_argumentos.py`)
- Transformación y procesamiento de datos usando funciones (`calculos_procesamiento.py`, `transformacion_de_datos.py`, `practica_funcion_formatear_texto.py`)

### `src/iterativas`
Contiene prácticas con bucles y control de iteraciones:
- Bucles `for` y `while` básicos (`bucleFor.py`, `bucleWhile.py`, `listasFor.py`, `datosWhile.py`)
- Uso de `break`, `continue` y `pass` (`break.py`, `continue.py`, `pass.py`, `breakContinue.py`, `continueDatos.py`)
- Bucles anidados y recorridos de colecciones (`bucleAnidado.py`, `iteradoDiccionario.py`, `cadenaFor.py`)
- Ejercicios de validación y simulación (`valContrasena.py`, `simulacionAprox.py`, `sistemaValidacion.py`, `proceDatos.py`)

## Cómo usar este proyecto

1. Abre el archivo Python de interés.
2. Ejecuta el script con tu intérprete Python.
3. Observa los ejemplos y modifica variables u condiciones para practicar.
